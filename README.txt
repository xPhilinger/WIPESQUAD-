WIPESQUAD Website
=================
Die Dateien index.html, nutzungsbedingungen.html, datenschutz.html, kontakt.html und style.css gehören zusammen.

WICHTIG: Google Sites kann diese Website NICHT als vollständige ZIP- oder HTML-Website importieren.

Veröffentlichung mit GitHub Pages:
1. Kostenloses GitHub-Konto verwenden.
2. Neues öffentliches Repository erstellen (z.B. wipesquad-site).
3. Alle Dateien aus diesem ZIP direkt in das Stammverzeichnis des Repositorys hochladen.
4. Settings > Pages > Build and deployment > Deploy from a branch > main / (root) auswählen.
5. Die veröffentlichte HTTPS-Adresse verwenden. Unterseiten enden auf /nutzungsbedingungen.html und /datenschutz.html.

Vor Veröffentlichung unbedingt die Platzhalter auf der Datenschutz- und Kontaktseite ersetzen und die rechtlichen Angaben prüfen.
Für Google Sites können Layout und Texte manuell übernommen werden.
